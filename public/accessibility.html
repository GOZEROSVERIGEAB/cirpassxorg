Our Commitment

CIRPASSX is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards to ensure we provide equal access to all users.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

cirpassx.org is fully conformant with WCAG 2.1 Level AA. Fully conformant means that the content fully conforms to the accessibility standard without any exceptions.

Accessibility Features

This website includes the following accessibility features:

Navigation

  • Skip navigation link to bypass repetitive content
  • Consistent navigation structure across all pages
  • Logical heading hierarchy (h1-h6)
  • ARIA landmarks for screen reader navigation
  • Focus indicators visible on all interactive elements

Visual Design

  • Color contrast ratios meeting WCAG AA standards (minimum 4.5:1 for normal text, 3:1 for large text)
  • Information not conveyed by color alone
  • Responsive design supporting zoom up to 200%
  • Readable font sizes with relative units
  • Sufficient spacing between interactive elements

Content

  • Plain language and clear writing
  • Descriptive link text (no "click here" links)
  • Table headers and captions for data tables
  • Alternative text for informative images
  • Code examples with proper syntax highlighting contrast

Interaction

  • Full keyboard accessibility
  • No keyboard traps
  • Visible focus states
  • Support for reduced motion preferences
  • No content that flashes more than three times per second

Technologies Used

This website relies on the following technologies for accessibility:

  • HTML5 semantic elements
  • WAI-ARIA for enhanced accessibility
  • CSS for visual presentation
  • JavaScript (progressive enhancement only)

Compatibility

This website is designed to be compatible with:

  • Recent versions of major browsers (Chrome, Firefox, Safari, Edge)
  • Screen readers (NVDA, JAWS, VoiceOver, TalkBack)
  • Screen magnification software
  • Speech recognition software
  • Keyboard-only navigation

Known Limitations

While we strive for full accessibility, some limitations may exist:

  • JSON/Code examples: Long code blocks may require horizontal scrolling on smaller screens. We provide downloadable versions as alternatives.
  • External links: Links to external resources (GitHub, standards bodies) may lead to sites with different accessibility levels.

Feedback

We welcome your feedback on the accessibility of cirpassx.org. If you encounter accessibility barriers or have suggestions for improvement, please contact us.

Contact Information

Email: accessibility@cirpassx.org
Response time: We aim to respond within 5 business days.

Enforcement Procedure

If you are not satisfied with our response to your accessibility concern, you may escalate the issue to your national enforcement body. In Sweden, this is the Agency for Digital Government (DIGG).

Technical Specifications

Accessibility of cirpassx.org relies on the following technologies to work with the particular combination of web browser and any assistive technologies or plugins installed on your computer:

  • HTML
  • WAI-ARIA
  • CSS

These technologies are relied upon for conformance with the accessibility standards used.

Assessment Approach

CIRPASSX assessed the accessibility of this website by the following approaches:

  • Self-evaluation using WCAG 2.1 guidelines
  • Automated testing with accessibility tools (axe, WAVE)
  • Manual testing with keyboard navigation
  • Testing with screen readers (VoiceOver, NVDA)

Applicable Standards

This statement applies to compliance with:

  • WCAG 2.1 Level AA
  • EU Web Accessibility Directive (2016/2102)
  • EN 301 549 v3.2.1
  • European Accessibility Act (2019/882)
