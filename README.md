# CIRPASSX Standard

Circular Product Passport Exchange — Open data standard for the circular economy.

- **Current Version:** [v1.0.0-draft](specification.html) (2026-06-05)
- **Planned Version:** [v1.1.0-draft Roadmap](ROADMAP-v1.1.0.md) — EU DPP interoperability, GS1 Digital Link, Exchange API, Verification model
- **Domain:** https://cirpassx.org
- **Standard:** `.org` (this repo) — open, neutral, implementable by any third party
- **Registry Service:** `.com` — paid implementation (not part of this standard)

## Repository Structure

| File | Description |
|------|-------------|
| `specification.html` | Full technical specification |
| `schema/v1/product.schema.json` | JSON Schema for validation |
| `context/v1/context.jsonld` | JSON-LD context for semantic interoperability |
| `examples/` | Example product documents |
| `ROADMAP-v1.1.0.md` | v1.1.0 development roadmap |

## Standards Alignment

- EU Digital Product Passport (ESPR)
- W3C Verifiable Credentials 2.0
- JSON-LD 1.1
- Schema.org
- GS1 Digital Link
- EPCIS 2.0
- UN Transparency Protocol (UNTP)
- EN 45554:2020 (Repairability)
